## Navigation

Navigation lives in the `Navbar` component. The tab strip is **Predict, PyPI, npm, News, Events, Leaderboard**. There is no home page: `/` redirects to `/predict`. When signed in, the navbar shows your bits balance, and the avatar opens a menu with **Dashboard**, **Settings**, and **Sign out**. Signed-out visitors can browse every page; betting is gated at the buy action.

## Predict

`PredictPage` is the landing page and the only place to buy contracts. It builds a bet slip:

- Search and add packages (up to 10). One package makes a single contract; two or more make a basket with a "how many must hit" count.
- Pick **Vulnerability happens** (YES) or **No vulnerability** (NO). NO is only available on packages with a CVE in the last 100 days and uses CVSS only.
- Set a CVSS threshold per package, an EPSS scenario target (single-package YES slips), a duration of 7, 14, or 30 days, and a stake (chips of 25, 100, 250, 500, or a custom amount; minimum 10).
- With a basket, a **Legs that must hit** slider sets how many members must win (for example "any 1 of 3").
- **If it hits**, **Win chance**, and **Max loss** update as you adjust. An **import manifest** button pulls in the packages you depend on.
- **Buy slip** deducts the stake. Signed-out users get a signup prompt instead.

## Dashboard

`DashboardPage` — authenticated users see their open contracts, resolved history, bits balance over time (`BitTimeline`), and per-contract P&L. Open contracts show their mark-to-model value (see [Prediction Markets](/docs/concepts/prediction-markets)). Statuses are open, won, lost, expired, or sold.

![Dashboard with stat cards, balance over time, active contracts, and history](https://assets.polydelve.com/screenshots/dashboard.png)

## Leaderboard

`LeaderboardTable` — all users ranked by bits balance, with search. Shows rank, username, balance, total/open contracts, and win rate. Clicking a row expands the user's contract history.

## Settings

`SettingsPage` — reached via the avatar menu. Users can:
- **Change username** — inline edit with uniqueness validation (`PATCH /users/me`)
- **Upload avatar** — file picker → presigned PUT to S3 → `PATCH /users/me` with the public URL
- **Sign out**

![Settings page showing username, balance, Change username and Sign out](https://assets.polydelve.com/screenshots/settings.png)

### Auth flow

New users are blocked by `UsernameModal` on first login until they choose a valid username (3–20 chars, letters/numbers/underscores). Any existing username that doesn't match this pattern (for example one that looks like an Auth0 sub or email) is treated as unset and triggers the same modal.

## EPSS chart

`EpssChart` renders a time-series line of daily EPSS scores for a package. CVE publication dates appear as scatter points on the same axis, colored by CVSS severity. This lets users see how exploitation risk evolved after each disclosure.

## Bits display

`BitIcon` appears next to the balance in the navbar. Balance is fetched from `GET /users/me` and kept in local React state — no global store. It refreshes after you buy a contract; resolved payouts appear on the next load.
