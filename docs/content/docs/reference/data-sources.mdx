## Provenance Table

| EPSS | FIRST bulk CSV (`epss_scores-DATE.csv.gz`) | `epss` / `epss-history` | Every `refresh` (3x daily; file updates daily) | Never loop the FIRST REST API |

## EPSS

Exploit Prediction Scoring System scores are published by FIRST as a daily bulk CSV (`https://epss.empiricalsecurity.com/epss_scores-DATE.csv.gz`). The ETL downloads the file, falling back to yesterday's if today's isn't up yet, and joins it against tracked CVEs; **do not substitute a per-CVE loop against the FIRST REST API**. The `epss` job updates `packages.epss_score` and snapshots changes into `epss_history`; `epss-history` (`scripts/ingest_epss_history.py`) backfills historical snapshots from the same daily files.

## OSV

The Open Source Vulnerabilities database is the source for CVE metadata used during contract settlement. The `cve` job (`make build-cve-history`) downloads the OSV bulk zip per ecosystem and writes OSV ID, CVE ID, severity and CVSS vector/score to `cve_history`. It also runs in every scheduled `refresh` to catch late-arriving records.

## npm Downloads

Weekly download counts for npm packages come from the npm downloads API, fetched by the `packages` job (and the `seed` job). There is no webhook trigger.

## PyPI Downloads

PyPI download counts come from a BigQuery query against the public PyPI dataset (`bigquery-public-data.pypi.file_downloads`), run by the same `packages` job. It requires Google Cloud credentials (`GOOGLE_APPLICATION_CREDENTIALS` or Workload Identity).

## News

News articles are sourced via the Exa API (`EXA_API_KEY`). The `news` job queries Exa with security-focused queries, then sends results through OpenAI gpt-5.4-mini for structured extraction and tagging before storing them. If the Exa key is absent the job will fail; ensure the secret is present in the environment or Secrets Manager before scheduling.

## MAL Advisories

Malicious package advisories are a subset of OSV. The `mal` job downloads the OSV bulk zips, keeps records whose IDs start with `MAL-`, and loads them into `mal_advisories`. Run it with `make etl-mal` (re-downloads) or `make etl-mal-cached`. `make etl-packages` only sets the `has_mal_advisory` flag on packages. If the job reports zero rows unexpectedly, check for OSV schema changes.
